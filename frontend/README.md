# Resume Intelligence Frontend

Complete React + Vite frontend for the deployed AI Resume Screening API.

Live backend: https://resume-analyzer-backend-sw59.onrender.com

Features: cinematic dark/glass landing page, live model metadata, localStorage demo authentication, PDF drag-and-drop, technical profile input, AI Match Agent, Top-5 career matches, relative match score, confidence indicator, decision margin, prediction strength, skill intelligence, sector intelligence, specialized role display, local analysis history, responsive layout.

Run: `npm install` then `npm run dev`.

Production build: `npm run build`.

Authentication is intentionally a browser-local prototype and is not production security.
